# 风铃岛探险队 · 网页版

三至六年级上下册，八册61关。操作玩法、英语点读、录音对话、重玩与独立进度。

## 试玩

https://contralogik.github.io/windbell-island-english/

点击物体与英语可听读；拖放或先点道具再点目标；点击空地/WASD移动，E操作附近目标。每册第一关开放，完成后依次解锁。教材地图可打开自由试学。

## 录音与数据

通过HTTPS打开。第一次可点“检查设备英语识别”准备组件；识别使用设备CPU，在浏览器的Worker中运行，不把录音上传到服务器。组件和模型由本网站提供，不依赖第三方语音服务或API Key。录音时可选择麦克风，并通过音量条确认设备收到声音。无声录音会提示检查麦克风，不会猜成单词；识别前会裁掉首尾静音并提高轻声音量。录音可回听、改正转写、保存、下载、删除；识别文字不是发音评分。识别较慢或不支持时，仍可回听并填写文字或使用文字回答。

游戏进度与录音只保存在当前浏览器。不同网址/设备的存储彼此独立。教材地图支持导出/导入进度；浏览器无法下载时，也可查看备份文本，在另一设备粘贴导入。还可恢复导入前的进度；录音可在原设备逐段下载。

本版覆盖核心词句与操作关卡，未逐页制作全部歌曲、故事全文与练习。地图显示书内印刷页码。六下严格为四单元和一个八幕Recycle。
